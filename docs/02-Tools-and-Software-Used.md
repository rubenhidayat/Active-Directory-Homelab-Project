# 02 - Tools and Software Used

**Virtualization** : Oracle Virtual Box

**Operating Systems** : Windows Server 2022 Standard, Server Core (`DC01`). Windows 11 Enterprise (`CLIENT01`), both free evaluation editions.

**AD & Windows Administration**: Active Directory Domain Services. DNS Server role. Group Policy Management Console (GPMC). Active Directory Users and Computers (ADUC). RSAT. Computer Management (remote share admin on Server Core)

**Command-Line**: PowerShell (AD module, scripting, bulk operations) · sconfig · dcdiag, nslookup, gpresult, gpupdate, whoami, net use

>All tools used here are standard in real Windows-based corporate IT environments.
